## 🇪🇸 Español — Política de Privacidad

**CleanMacUSB** respeta plenamente la privacidad de sus usuarios.

1. **Sin recopilación de datos personales:**  
   **CleanMacUSB** NO recopila, almacena, rastrea, procesa ni transmite ningún tipo de información personal, identificadores de dispositivo, nombres de archivos ni contenido de las unidades de almacenamiento a servidores propios ni de terceros.
2. **Funcionamiento 100 % local:**  
   Todo el análisis y eliminación de archivos residuales (`.DS_Store`, `._*`, `.Trashes`, `Thumbs.db`, etc.) y la expulsión segura de dispositivos USB se ejecutan exclusivamente de manera local en el ordenador del usuario.
3. **Preferencias del usuario:**  
   Los ajustes de configuración (como el idioma seleccionado o la preferencia de ejecución en segundo plano) se guardan únicamente de forma local en el propio equipo del usuario (`%LOCALAPPDATA%\CleanMacUSB\settings.json`).
4. **Enlaces externos opcionales:**  
   La edición gratuita incluye enlaces voluntarios informativos (como soporte o donaciones vía PayPal) que solo se abren en el navegador predeterminado del usuario si este pulsa expresamente sobre ellos.

## 🇬🇧 English — Privacy Policy

**CleanMacUSB** fully respects user privacy.

1. **No Personal Data Collection:**  
   **CleanMacUSB** does NOT collect, store, track, process, or transmit any personal information, device identifiers, file names, or storage drive contents to any first-party or third-party servers.
2. **100% Local Processing:**  
   All scanning and removal of residual files (`.DS_Store`, `._*`, `.Trashes`, `Thumbs.db`, etc.) and safe hardware USB ejection are performed strictly locally on the user's computer.
3. **User Preferences:**  
   Application settings (such as selected interface language or background tray behavior) are stored exclusively on the user's local machine (`%LOCALAPPDATA%\CleanMacUSB\settings.json`).
4. **Optional External Links:**  
   The application includes optional external links (such as voluntary support via PayPal) that only open in the user's default web browser when explicitly clicked by the user.
